    Məlumat və fərziyyələr

    Həqiqi xəritə konturları

    OSM/Geofabrik kəsiyindən küçələr və bina konturları, saxlanılmış layihə fayllarından metro və R2/R14 həndəsələri istifadə olunur. Tam mövcud pilot sahəsi göstərilir. Bu, bütün Bakı üçün marşrut modeli deyil.

    Vizual fərziyyələr

    Binaların 12 m hündürlüyü, metro dərinliyi və qat ayrılması illüstrativdir. Metro yerüstü görünüşdə sxematik şəbəkə qatı kimi göstərilir; bütün xəttin faktiki yeraltı olması iddia edilmir. Giriş bağlantıları əlavə edilməyib.

    Səfər simulyasiyası

    Mərhələ növləri, saniyələr, dayanma və park nöqtəsi UI sınağı üçündür. Real R2 fraqmentinin həndəsəsi üzərində nümayiş etdirilir; piyada və velosiped giriş icazələri təsdiqlənməyib. Metro hissəsinə keçid həndəsəsi yoxdur: oynatma orada dayanır və əlaqə yolu çəkilmir.

    WebGLsiz 2D ehtiyat görünüşünü aç

    Asılılıqlar

    Three.js 0.180.0 və lisenziyası yerli resurslardır. Bu interfeys mövcud routing API ilə eyni serverdə açılır.
